# 🍓 Клубничные облака 

Браузерный платформер на HTML, CSS и JavaScript (Canvas), без движков и сборки.

## Запуск
Откройте папку в VS Code и запустите `index.html` через расширение Live Server (ES-модули требуют локального веб-сервера).

## Игра
Соберите три сердечка и доберитесь до замка. Опасные шипы и падение приводят к поражению. Рекорд сохраняется в localStorage.

Управление с компьютера: стрелки или A/D для движения, Space/W/стрелка вверх для прыжка. На сенсорных устройствах появляются кнопки управления прямо в игровом поле.

В правом верхнем углу игры расположено меню с командами старта/продолжения, паузы и перезапуска. При открытии меню игра ставится на паузу. Счёт и рекорд показаны внутри игрового поля. Подсказки клавиш на экране нет.

Анимированная зайка, сияющие сердечки, искры при сборе, фоновое мерцание и конфетти после победы. Все эффекты рисуются Canvas без внешних библиотек.
